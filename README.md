# 🤖 SmartBiz AI Assistant

An AI-powered customer support chatbot for small businesses. Built with Python, Flask, and SQLite. Features real-time FAQ responses, order booking, and an admin dashboard.

**Built by:** Abdul Nafeue Babar

---

## ✨ Features

- 💬 **Instant Customer Support** — 24/7 automated responses
- 📋 **FAQ Answering** — Timing, location, price, delivery, payment
- 🛒 **Order Booking System** — Customers can place orders directly
- 📊 **Admin Dashboard** — Real-time order management with analytics
- 💾 **Database Storage** — SQLite for orders and chat history
- 🎨 **Modern UI** — WhatsApp-style chat interface
- 📱 **Mobile Responsive** — Works on all devices

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Backend | Python 3.13, Flask 3.0 |
| Database | SQLite (Flask-SQLAlchemy) |
| Frontend | HTML5, CSS3, JavaScript |
| AI Logic | Keyword Matching + FAQ Engine |
